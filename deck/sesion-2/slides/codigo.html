El dato nunca se vuelve código.

Inyección SQL, XSS e inyección de comandos son la misma falla en tres intérpretes distintos.

La frase resume A05 completa. SQL: el dato se pega en una consulta y el motor lo ejecuta. XSS: el dato se pega en HTML y el navegador lo ejecuta. Comandos: el dato se pega en una línea de shell y el sistema lo ejecuta. El control es siempre el mismo: mantener el dato separado del código, con la API que el intérprete ofrece para eso.
