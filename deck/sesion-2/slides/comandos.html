Antes

subprocess.run(cmd, shell=True)

if not re.fullmatch(r"[A-Za-z0-9_-]{1,40}", nombre):

with tarfile.open(os.path.join(REPORTES, f"{nombre}.tgz"), "w:gz") as tar:

Dos controles: una lista blanca que impide ; $( ) / .. y una librería que no pasa por el intérprete.

Si de verdad hay que llamar un programa externo: subprocess.run con una lista de argumentos y sin shell=True; el sistema no interpreta ; ni $(). La lista blanca además cierra el path traversal (../../fuera), que es la segunda amenaza del generador en el modelo.
