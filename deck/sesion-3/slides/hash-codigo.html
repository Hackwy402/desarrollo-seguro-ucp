Argon2id con la librería, no a mano

Antes

def hashear(clave):
  return hashlib.md5(clave.encode()).hexdigest()  # 962b0054…

Después

from argon2 import PasswordHasher
PH = PasswordHasher()    # t=3, m=64 MiB, p=4: sobre el mínimo de OWASP
def hashear(clave): return PH.hash(clave)
# $argon2id$v=19$m=65536,t=3,p=4$sal$hash

Política (ASVS V6 y NIST 800-63B): largo mínimo (8; se recomiendan 15; la billetera exige 12), sin reglas de composición, contra una lista de claves comunes y sin cambio periódico forzado.

Si su framework ya trae hash de contraseñas (Django, Spring Security, ASP.NET Identity, Laravel), úsenlo y verifiquen el algoritmo y los parámetros. La prueba del registro con una frase con espacios existe para que nadie meta una regla de «solo alfanuméricos».
