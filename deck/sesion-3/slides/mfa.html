No todo segundo factor resiste el phishing

FactorResiste phishingComentario
SMS / correo con códigoNoSIM swapping; el código se reenvía al sitio falso
TOTP (app autenticadora)NoMejor que SMS, pero el usuario lo teclea en el sitio falso
Push con número a confirmarParcialEvita la fatiga de notificaciones; no el proxy en tiempo real
Passkeys (FIDO2 / WebAuthn)SíLa firma va atada al dominio: en el sitio falso no hay llave

Para su proyecto: MFA obligatorio para administradores (ASVS V6, nivel 2) y passkeys como opción para todos.

La diferencia clave: con TOTP el usuario es quien decide a qué sitio le entrega el código, y se equivoca. Con WebAuthn el navegador firma un reto que incluye el origen; en ucp-login.example la llave de ucp.edu.co no existe. passkeys.dev tiene librerías para cada lenguaje.
