OWASP ASVS 5.0: requisitos que se pueden verificar

El Top 10 dice qué sale mal. ASVS dice qué debe cumplir la aplicación, requisito por requisito, para poder probarlo.

L1

Base

El mínimo para toda aplicación. Es la meta del proyecto integrador.

L2

Estándar

Aplicaciones con datos sensibles o transacciones.

L3

Alta criticidad

Salud, finanzas, infraestructura crítica.

La versión 5.0.0 (mayo de 2025) reorganizó capítulos y agregó frontend web, tokens autocontenidos y OAuth/OIDC. En el proyecto, cada amenaza del modelo debe terminar en uno o varios requisitos ASVS.
