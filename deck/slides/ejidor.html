EJERCICIO 2 · 5 MIN · ¿QUÉ PRINCIPIO SE VIOLA?

Consultar una factura

Antes

@app.get("/facturas/<int:id>")
@login_requerido
def ver_factura(id):
  f = Factura.query.get_or_404(id)
  return jsonify(f.a_dict())

Después

@app.get("/facturas/<int:id>")
@login_requerido
def ver_factura(id):
  f = Factura.query.filter_by(
    id=id, cliente_id=g.usuario.id
  ).first_or_404()
  return jsonify(f.a_dict())

Respuesta: mediación completa. Estar autenticado no es estar autorizado; cambiando el id se leen facturas ajenas (A01, IDOR).

Es la categoría número uno del OWASP Top 10:2025 y del API Security Top 10 (BOLA). El control va en el servidor y en cada consulta, idealmente en una capa común para no depender de que cada desarrollador lo recuerde.
