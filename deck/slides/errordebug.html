Lo que revela la insegura

Rutas internas, versión de Python, el código de la línea que falló y, abajo: «You can execute arbitrary Python code in the stack frames».

Abrir http://127.0.0.1:5001/error en el navegador en vivo. La consola de Werkzeug pide un PIN, pero exponerla ya es un error grave. Causa: debug=True, SECRET_KEY en el código y CORS "*": volver al ejercicio 3.
