2 · Docker Engine (repositorio oficial)

# llave y repositorio de Docker:
# ver la guía, sección 3
sudo apt install -y docker-ce \
  docker-ce-cli containerd.io \
  docker-buildx-plugin \
  docker-compose-plugin
sudo usermod -aG docker $USER
# cerrar sesión y volver a entrar
docker run --rm hello-world

El paso que más falla: olvidar cerrar sesión después de usermod; sin eso, docker pide sudo. Docker se instala desde su repositorio oficial con la llave firmada, no con el paquete docker.io de Ubuntu ni con scripts copiados de un blog.
