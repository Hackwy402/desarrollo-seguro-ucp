Formato de la salida de check-env.sh

== Herramientas base ==
  [OK]    docker daemon  en ejecución sin sudo
  [OK]    compose        Docker Compose version …
== Herramientas de seguridad ==
  [OK]    semgrep        …
  [FALTA] zap            no se encontró zaproxy
== Entorno de práctica ==
  [OK]    juice-shop     responde en 127.0.0.1:3000

Resultado: entorno listo.

La meta es que todas las líneas salgan en OK. Una línea FALTA dice exactamente qué instalar. El archivo check-env-usuario.txt y el pantallazo de Juice Shop se suben como comentario en el issue del equipo.
